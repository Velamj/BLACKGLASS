# BLACKGLASS character and vehicle source art

These original meshes are generated by `Scripts/Art/Generate-Character-Meshes.py` using Python's standard library. No third-party models, textures, scans, game extracts or paid services are used. They are owner-authorized original project artwork. No separate public asset license is asserted.

The generator authors rounded and beveled loft profiles with smooth vertex normals: a fitted coat torso, separate flared coat tails, head with nose and ears, collar, sleeves, trouser legs, hair cap, boots, general trim, vehicle body, sloped cabin, tires and a thin hollow selection annulus. The annulus preserves the existing marker envelope and component scaling, while revealing the ground and feet through its center. The OBJ geometry uses centimeters with Z up and X forward. Each part is normalized around a nominal 100 cm envelope; the runtime component scales establish human and vehicle size.

Run the generator with Python, then run `Scripts/Art/Import-Character-Meshes.py` through the installed Unreal Python commandlet. The import uses the legacy FbxFactory, creates no collision, and refuses unowned asset replacements. `manifest.json` records each source mesh's dimensions, triangle count and SHA-256 hash. Imported assets live in `/Game/Characters`.

This is interim articulated static-mesh art. Capsule and hull collision remain authoritative. Hip and shoulder transforms animate the limbs; this is not a finished skeletal rig. Facial animation, fabric textures, hand articulation, vehicle interior and polished animation still require production work.
