# Fidelity ledger

Benchmark: the 1993 PC game as specified by the owner's master brief. Initial reference classifications follow that brief; detailed historical tuning still needs primary-source reference play. NEW marks additions requested for this successor. No original game asset or source is reused.

**No in-game playtest has occurred.** "Core prototype" means standalone C++ state tested in CI, without Unreal actors, animation, navigation, graphics, audio, input or UI. None of these rows establishes Milestone 1 completion. The core's cardinal cell grid is a test fixture, not the final game's movement or cover system.
